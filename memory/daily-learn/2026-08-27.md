## 📄 MySQL keyring组件安装.md

## 1、问题

MySQL 8.0.24版本开始存在一个bug https://bugs.mysql.com/bug.php?id=103684，如果没有安装keyring组件且log verbosity = 3时，在执行SELECT * FROM  performance_schema.keyring_component_status;后会在errlog中产生一条warning记录`[Warning] [MY-013712] [Server] No suitable 'keyring_component_metadata_query' service implementation found to fulfill the request`    。 



![image-20240228141253220](/Users/yangminghan/Library/Application Support/typora-user-images/image-20240228141253220.png)

![image-20240228141218748](/Users/yangminghan/Library/Application Support/typora-user-images/image-20240228141218748.png)

该bug在8.0.35中依然存在，虽然不影响使用，但会”污染“错误日志，影响监控系统对数据库实例健康情况的判断。



## 2、解决

解决该问题有两个方向的处理办法：控制错误日志输出，或安装keyring组件。

### 2.1 控制错误日志输出

- 修改log_error_verbosity=1，错误日志只输出error级别。这种操作会丢失错误日志中很多信息，不建议。
- 过滤MY-013712事件，前提是启用log_filter_interna。精确过滤，推荐使用

```
h:localhost u:root :db(none) [22:23:48]>show global variables like 'log_error_services';
+--------------------+----------------------------------------+
| Variable_name      | Value                                  |
+--------------------+----------------------------------------+
| log_error_services | log_filter_internal; log_sink_internal |
+--------------------+----------------------------------------+
1 row in set (0.00 sec)

h:localhost u:root :db(none) [22:23:07]>set global log_error_suppression_list='MY-013712';
Query OK, 0 rows affected (0.00 sec)

h:localhost u:root :db(none) [22:23:30]>show global variables like 'log_error_suppression_list';
+----------------------------+-----------+
| Variable_name              | Value     |
+----------------------------+-----------+
| log_error_suppression_list | MY-013712 |
+----------------------------+-----------+
1 row in set (0.00 sec)
```



### 2.2 安装keyring组件

不同于plugin在配置文件中指定参数 --early-plugin-load ，组件需要使用manifest文件告知服务器需要加载哪些组件。manifest文件命名为mysqld.my。 既可以全局指定，也可以local指定。
