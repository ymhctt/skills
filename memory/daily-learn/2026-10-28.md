# daily-learn 2026-10-28

## 01:00 — 跨日首轮 heartbeat 的文件创建纪律

- **场景**：`cron:memory_refine` 在 00:00 跨日边界运行时，日志写进了 10-27 文件；01:00 再跑时今天（10-28）的 daily 文件尚不存在。
- **正确做法**：先 `ls memory/2026-10-28.md` 确认存在与否 → 不存在则用 `cat >` 新建（首行标题 + 指针段），再用 `cat >>` 追加本轮条目。
- **红线**：`write` 工具会**覆盖整个文件**（TOOLS.md 已固化），对已存在的 daily 文件追加内容必须用 `cat >>` 或 `edit`，否则丢历史。
- **新增教训**：跨日后的第一个整点（01:00）应该是「建文件 + 记录」的固定动作，且要在日志里留一行指针说明 00:00 那轮记录在哪，避免下个 session 以为 00:00 没跑过。
