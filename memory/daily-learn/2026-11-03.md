## 📄 MySQL sysdate()不能使用索引.md

## 问题

分析慢SQL是发现一条SQL 在timestamp字段上存在索引的情况下，范围查找不能使用索引；将sysdate()改成now()后正常如下

```
mysql> show create table t1;
+-------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Table | Create Table                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
+-------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| t1    | CREATE TABLE `t1` (
  `id` int NOT NULL AUTO_INCREMENT,
  `c` int DEFAULT NULL,
  `name` varchar(255) DEFAULT NULL,
  `ttt` varchar(255) DEFAULT NULL,
  `tttddd` varchar(255) DEFAULT NULL,
  `tttdddd` varchar(255) DEFAULT NULL,
  `ttstdddd` varchar(255) DEFAULT NULL,
  `brtime` timestamp NULL DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `udx1` (`c`),
  KEY `idx1` (`name`),
  KEY `idx_1` (`brtime`)
) ENGINE=InnoDB AUTO_INCREMENT=10000 DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci |
+-------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
1 row in set (0.00 sec)



mysql> explain select * from t1 where brtime>sysdate() - interval 2 day;
+----+-------------+-------+------------+------+---------------+------+---------+------+------+----------+-------------+
| id | select_type | table | partitions | type | possible_keys | key  | key_len | ref  | rows | filtered | Extra       |
+----+-------------+-------+------------+------+---------------+------+---------+------+------+----------+-------------+
|  1 | SIMPLE      | t1    | NULL       | ALL  | NULL          | NULL | NULL    | NULL |  211 |    33.33 | Using where |
+----+-------------+-------+------------+------+---------------+------+---------+------+------+----------+-------------+
1 row in set, 1 warning (0.00 sec)

mysql> explain select * from t1 where brtime>now() - interval 2 day;       
+----+-------------+-------+------------+-------+---------------+-------+---------+------+------+----------+-----------------------+
| id | select_type | table | partitions | type  | possible_keys | key   | key_len | ref  | rows | filtered | Extra                 |
+----+-------------+-------+------------+-------+---------------+-------+---------+------+------+----------+-----------------------+
|  1 | SIMPLE      | t1    | NULL       | range | idx_1         | idx_1 | 5       | NULL |    1 |   100.00 | Using index condition |
+----+-------------+-------+------------+-------+---------------+-------+---------+------+------+----------+-----------------------+
1 row in set, 1 warning (0.00 sec)
```



## 原因分析

- 查看官方文档，sysdate和now都是返回当前的日期和时间；但sysdate()是该函数执行时动态获取时间，NOW()是语句开始时就获取时间，这时优化器进行SQL解释时，已经能确认NOW()返回值，但sysdate()不能，所以不能评估成本，于是优化器只能对sysdate()选择全表扫描，就now()就可以用索引了。
