# RHEL 8.10 数据库服务器自启动服务关闭清单

> 来源：2026-07-16 daily-learn / 客户场景：华泰 RHEL 8.10 数据库服务器精简

## 一、必须保留的服务（数据库运行依赖）

| 服务 | 理由 |
|------|------|
| `mariadb` | 数据库核心 |
| `sshd` | 远程管理必须 |
| `chronyd` | **Galera 集群要求节点间时间同步（误差 >50ms 会导致复制异常）** |
| `rsyslog` | 系统日志记录，排障必需 |
| `firewalld` / `iptables` | 安全防护必须 |
| `systemd-journald` | systemd 核心日志组件 |
| `dbus` | systemd 依赖的系统消息总线 |
| `polkit` | 权限管理 |
| `auditd` | **安全审计（合规要求）** |
| `tuned` | 性能调优框架（建议保留，用于 database-throughput profile） |
| `network` | 网络连接（NetworkManager / network-scripts） |
| `crond` | **定时任务（备份脚本、日志轮转、所有 cron 依赖）** |

## 二、可以安全关闭的服务

### A 类：桌面/用户交互类（100% 可关）

| 服务 | 关闭理由 |
|------|----------|
| `cups`、`cups.socket`、`cups.path` | 打印服务，DB 服务器不需要 |
| `avahi-daemon` | mDNS/DNS-SD，DB 服务器不加入零配置网络，且可能泄露服务信息 |
| `bluetooth`、`bluetooth.service` | 蓝牙，服务器无硬件 |
| `spice-vdagentd` | SPICE 虚拟机桌面代理，仅虚拟桌面需要 |
| `gsd-*` 系列（GNOME Settings Daemon） | 桌面设置守护进程，无桌面环境 |

### B 类：硬件/设备管理类（通常可关）

| 服务 | 关闭理由 |
|------|----------|
| `pcscd` | 智能卡读卡器，DB 服务器不需要 |
| `irqbalance` | **注意**：单路 CPU 可关，多路 NUMA 建议保留 |
| `smartd` | 视情况：硬件 RAID 控制器可关（控制器自带监控），否则建议**保留** |
| `lm_sensors` | 硬件传感器监控，如无 IPMI/BMC 外部监控可关 |

### C 类：网络/文件共享类（确认不用即可关）

| 服务 | 关闭理由 |
|------|----------|
| `nfs-server`、`samba` | 文件共享服务，DB 服务器通常不提供 |
| `httpd`、`nginx` | Web 服务（除非用作监控/管理入口） |
| `squid` | 代理服务 |

## 📄 Linux内存管理神器：smem工具.md

`smem` 是Linux系统上的一款可以生成多种内存耗用报告的命令行工具。与现有工具不一样的是 `smem` 可以报告 PSS【Proportional Set Size（按比例占用大小）】，这是一种更有意义的指标。可以衡量虚拟内存系统的库和应用程序所占用的内存数量。

由于大部分的物理内存通常在多个应用程序之间共享，名为驻留集大小（RSS）的这个标准的内存耗用衡量指标会大大高估内存耗用情况。PSS这个参数而是衡量了每个应用程序在每个共享内存区中的「公平分配」，给出了一个切合实际的衡量指标。

## 1. 安装 smem 工具

如果你使用的是 Fedora 19 以上系统， `smem` 默认在存储库中，因此你可以使用 `yum`来安装它：

```
$ sudo yum install smem
```

对于 Ubuntu 用户，可以使用 `apt-get` 命令来安装  `smem` ：

```
$ sudo apt-get install smem
```

如果无法正常安装的话，可以下载它的源码直接安装，地址为：https://www.selenic.com/smem/download/

## 2. smem 工具常见用法

默认情况下， `smem` 将显示每个正在运行的进程及所使用的内存。在这里，你可以留意 RSS 相对于 USS 和 PSS 的大小，可以看到它明显高于另外二者。

```
$ smem
```

![图片](Linux%E5%86%85%E5%AD%98%E7%AE%A1%E7%90%86%E7%A5%9E%E5%99%A8%EF%BC%9Asmem%E5%B7%A5%E5%85%B7.assets/640-20220211111628645)

此外， `smem` 还可显示每个库所使用的内存。这个结果比较长，可能需要耗费一些时间，取决于你的系统。

```
$ smem -m
```

这个命令产生的结果太多了，如果我们想要查看特定应用程序使用内存情况，例如 Firefox，那么我们可以配合 `grep` 命令使用，同时使用 `-p` 选项以百分比形式查看内存使用情况。

```
$ smem -m -p | grep firefox
```

![图片](Linux%E5%86%85%E5%AD%98%E7%AE%A1%E7%90%86%E7%A5%9E%E5%99%A8%EF%BC%9Asmem%E5%B7%A5%E5%85%B7.assets/640-20220211111628638)

`smem` 命令还可以显示每个**用户**的内存使用情况，需要使用 `-u` 选项：

```
$ smem -u -p
```
