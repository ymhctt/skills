### MogDB prpcengage 索引损坏
- 错误截图: `ERROR 1712 (HY000): Index prpcengage is corrupted`
- 误以为是 MogDB → 实际是 MySQL（1712 错误码不是 MySQL 标准 → 国产分支/MySQL 内部自定义）
- 关键风险: 表只有主键 → PK = 聚簇索引 = 数据本身
- 给爸爸的方案: 先 IGNORE INDEX 验证数据 → 定位具体索引 → ALTER TABLE ENGINE=InnoDB 重建（需停业务）
