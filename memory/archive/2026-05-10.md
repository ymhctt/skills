## 📄 ORACLE-_PG迁移方案.md

###  1 收集ORACLE源库信息

- 源库总大小

- 源库各表信息（用户名、表名、行数、索引总大小、是否包含LOB字段、是否分区表）

用户名、表名、行数、索引总大小（普通表）

用户名、表名、行数、索引总大小（分区表）

包含LOB的表

- 源库除表以及索引之外其他对象转化问题（DBLINK/约束/视图/序列/函数/存储过程/触发器等）
- 源库表结构转换后是否存在问题（保留字、默认值等）

### 2 收集PG目标端信息

- PG数据库版本
- PG端主机cpu核数以及其他系统性能，例如io性能、内存使用率等。

### 3 确定需要迁移的对象

- 需要导出的用户
- 需要导出的表，是否全表导出或者部分表导出
- 需要导出的索引和约束
- 需要导出的除表和索引以外的其他对象（DBLINK/约束/视图/序列/函数/存储过程/触发器等）

### 4 安装ora2pg-PG端

- perl 5.10版本以上

```
yum install -y perl perl-ExtUtils-CBuilder perl-ExtUtils-MakeMaker perl-Time-HiRes
yum -y install perl-DBI perl-DBD-Pg gcc
```

- 安装DBI

```
tar -xzvf DBI-1.643.tar.gz
cd DBI-1.643
perl Makefile.PL
make
make install   
```

- 安装oracle软件（静默）

```
/runInstaller -silent -ignoreSysPrereqs -showProgress -responseFile /home/oracle/soft/database/response/20210310.rsp
