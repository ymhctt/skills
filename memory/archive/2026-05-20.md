# 安装文档

容量规划  

CPU 规划  
搜索线程池大小 = int（核数 * 3/2） + 1  
写入线程池大喜 = 核数 + 1  
先计算：  
1每线程每秒处理请求数 = 1s/平均请求延时  
2处理峰值请求所需的并发数 = 峰值每秒请求数/每线程每秒处理请求数  
3所需节点数 = 峰值并发数/每节点线程池大小。  

磁盘&&分片大小  
●每个分片不超过50GB。（一般30-40GB）；日志单分片不超过40G，应用类搜索不超过20G；  

安装部署  

系统环境  
●创建专用账号启（比如elasticsearch，确保节点账号id一致)动服务，  
●系统参数 /etc/security/limits.conf 增加  

●关闭交换分区  

参数优化  
●master节点参数 2g  
●data节点内存 总内存不要超过系统内存一半 内存（1G）磁盘比例 （总数数据量除以16或者48）  
a，1:16 搜索类，并要求高，ssd  
b, 1:48--1:96 日志查询并发低，普通  
●单节点默认最大1000个分片  
●分片数量建议是节点倍数（确保均匀分布）  

角色配置参数配置  
●jvm调整 config/jvm.options 文件设置  
●master（3个节点起步）  
serverPrivate 为系统环境变量值为主机IP, 这样可集群相同角色节点使用同一份配置文件  
  

●data （，至少2个节点，避免数据丢失如果master，data在一台机器，端口调整)  

xpack认证开启（安全必选）  
关闭所有节点  
●xpack证书生成  
根据提示操作  

●拷贝 elasticsearch.keystore elastic-certificates.p12 到所有节点的config目录下  
●配置文件增加以下内容  

●启动集群所有节点，然后进行初始化密码操作  

●配置验证
