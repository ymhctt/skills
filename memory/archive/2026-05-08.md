## 📄 业务推动考核.md

## 一、公司业务

### 1.1 每月拜访10个新客户

每月考核对公客户经理，由业务部门负责人检查。

要求，书面反映所拜访客户的基本情况和结果。包括客户的经营项目、大致经营情况、大致的资产负债情况、我行拟介入客户的哪方面业务、是否有合作机会等。

奖惩金额：差一户处罚100元。

### 1.2 还后续贷客户执行“二三制”

按次考核对公客户经理，由信贷管理部经理检查。

要求，还后续贷客户，支行权限内的须在到期前2个月上报信管；支行权限外的须在到期前3个月上报信管。

奖惩金额：每户处罚100元。

### 1.3 业务正式受理后7天内完成上会准备

按次考核专审人，由信贷管理部经理检查。

要求，达到正式收件标准后，7天内专审人完成风险审查，申报书定稿及上会。

奖惩金额：每户处罚100。

### 1.4 还后续贷3天内放款

按次考核对公客户经理，由信贷管理部经理检查。

要求，存量客户还款后，3个工作日内上账。

奖惩金额：每户处罚100。

### 1.5 公私联动工资代发

按户考核对公客户经理，由业务部门负责人检查。

要求，至少代发上账一次，以上账人数考核。

奖惩金额：50人以下：每户奖励500元；50人及以上：每户奖励1000元。

### 1.6 转介客户营销

按次考核全行员工，由业务部门负责人检查。

情况一：公司条线人员转介绍。介绍人需提前报本部门负责人同意，介绍人享受业务金额的50%-60%，不承担基数。 

情况二：非公司条线人员转介绍。介绍人享受该笔业务对应买单奖励的50%-60%，不承担基数。

## 📄 pgbadger安装和使用.md

\#root身份

**1，yum install perl-ExtUtils-MakeMaker    perl-CPAN  perl-Text-CSV_XS  -y**

\# 上面的yum install  **perl-Text-CSV_XS  成功 ，该步骤可以省略**  2，perl -MCPAN -e'install Text::CSV_XS'

3，tar -zxvf pgbadger-11.6.tar.gz

 perl Makefile.PL

make && make install

**解压出来的README有比较全的使用说明**

**常用的例子：**pgbadger -b '2017-09-20 02:00:00' -e '2017-09-20 04:00:00'   postgresql-2017-09-20_023510.csv -o pg_out_bwt_db1_s.html

**--不指定-b/-e 则是全文件**

**-b 开始时间**

**-e 结束时间**

**-o 输出文件**

**问题：：：：1，**

[root@postgres ~/pgbadger-9.2 10:08:12&&12]# perl Makefile.PL

**Can't locate ExtUtils/MakeMaker.pm in** @INC (@INC contains: /usr/local/lib64/perl5 /usr/local/share/perl5 /usr/lib64/perl5/vendor_perl /usr/share/perl5/vendor_perl /usr/lib64/perl5 /usr/share/perl5 .) at Makefile.PL line 1.

BEGIN failed--compilation aborted at Makefile.PL line 1.

[root@postgres ~/pgbadger-11.6 10:08:19&&13]#**yum install perl-ExtUtils-MakeMaker**

**解决:**

**yum -y install perl-CPAN** 

**perl -MCPAN -e'install Text::CSV_XS'**
