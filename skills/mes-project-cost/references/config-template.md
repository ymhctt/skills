# 人员成本配置模板

> 复制此文件到 `.workbuddy/memory/project-configs/` 目录下，按项目维护。文件名：`<合同编号>-staff.json`

## 格式

```json
{
  "staff": [
    {
      "name": "张三",
      "monthly_salary": 23000,
      "role": "项目经理"
    },
    {
      "name": "李四",
      "monthly_salary": 19000,
      "role": "实施工程师"
    }
  ],
  "notes": "管理岗位人员也按此方式配置"
}
```

## 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 员工姓名，需与 MES 报工记录中的执行人姓名一致 |
| monthly_salary | number | 月薪（元） |
| role | string | 岗位角色（可选，用于报告展示） |

## 时薪计算规则

脚本自动按以下公式计算：

```
时薪 = 月薪 ÷ (21.75 × 8) = 月薪 ÷ 174
```

## 预算计算规则

```
交付+维保预算 = PO 自有金额合计 × 15%
交付部门利润 = 预算 × 利润率（默认 50%）
最大允许成本 = 预算 - 利润 = 预算 × (1 - 利润率)
```

可在 SKILL 调用时指定利润率，默认 50%。
